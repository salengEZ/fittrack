# FitTrack — เว็บติดตามสุขภาพและการออกกำลังกาย

## สิ่งที่ต้องมีก่อนรัน
- Python 3.9+
- MySQL Server (ติดตั้งและเปิดใช้งานไว้แล้ว)

## ขั้นตอนติดตั้ง

1. ติดตั้ง library ที่ต้องใช้
   ```
   pip install -r requirements.txt
   ```

2. สร้างฐานข้อมูล — เปิด MySQL แล้วรัน
   ```
   mysql -u root -p < schema.sql
   ```

3. แก้ไขค่าเชื่อมต่อฐานข้อมูลในไฟล์ `config.py` ให้ตรงกับเครื่องคุณ
   (user, password, host)

4. รันเว็บ
   ```
   python app.py
   ```

5. เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:5000`
   - ระบบจะพาไปหน้า login ก่อน กด "สมัครสมาชิก" เพื่อสร้างบัญชีแรก

## โครงสร้างโปรเจกต์
```
fittrack/
├── app.py              # จุดเริ่มต้นของเว็บ + หน้า dashboard
├── config.py            # ตั้งค่าการเชื่อมต่อฐานข้อมูล
├── schema.sql            # สร้างฐานข้อมูลและตารางทั้งหมด
├── requirements.txt
├── routes/
│   ├── auth.py          # สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ
│   ├── health.py        # บันทึกข้อมูลสุขภาพ
│   └── workout.py       # บันทึกการออกกำลังกาย
├── templates/            # หน้าเว็บ (HTML)
└── static/css/           # สไตล์
```

## ฟีเจอร์ที่ทำไว้แล้ว
- สมัครสมาชิก / เข้าสู่ระบบด้วยอีเมล (รหัสผ่านเข้ารหัสด้วย werkzeug)
- หน้า Dashboard แสดง BMI, เปอร์เซ็นต์ไขมัน, กิจกรรมล่าสุด, ประวัติย้อนหลัง
- เพิ่ม / แก้ไข / ลบ บันทึกสุขภาพ (น้ำหนัก, ไขมัน) พร้อมตรวจสอบข้อมูล (ห้ามติดลบ, ห้ามเป็นวันที่อนาคต)
- เพิ่ม / แก้ไข / ลบ บันทึกการออกกำลังกาย
- หน้าประวัติแบบเต็ม (`/history`) รวมทั้งสุขภาพและออกกำลังกาย
- **ระบบ Admin** (เห็นเมนูเฉพาะ member ที่ตั้ง `is_admin = 1`):
  - จัดการสมาชิก — ระงับ/เปิดใช้งาน, ลบสมาชิก
  - จัดการประเภทออกกำลังกาย — เพิ่ม/ลบ
  - รายงานสรุปผล — จำนวนสมาชิก, จำนวนครั้งออกกำลังกาย, แคลอรี่รวม, Export CSV

## วิธีตั้งบัญชี Admin คนแรก
1. สมัครสมาชิกผ่านเว็บตามปกติ 1 บัญชี
2. เข้า MySQL แล้วรัน:
   ```sql
   UPDATE member SET is_admin = 1 WHERE email = 'your-email@example.com';
   ```
3. Login ใหม่อีกครั้ง จะเห็นเมนู Admin ใน sidebar

## ที่ยังไม่ได้ทำ (ทำต่อได้)
- หน้าโปรไฟล์แก้ไขข้อมูลส่วนตัว
- กราฟแนวโน้มแบบ interactive (ตอนนี้มีแค่ตาราง)
- แก้ไขข้อมูลสมาชิกจากฝั่ง Admin (ตอนนี้ทำได้แค่ระงับ/ลบ)
